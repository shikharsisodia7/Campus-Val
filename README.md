# CampusVal

Academic planning support for Santa Clara University students — Degree Plan, Quarter Plan, and Tentative Degree Plans, grounded in real SCU policy and each student's own progress.

pnpm workspace monorepo: `artifacts/scu-advising` (web frontend), `artifacts/api-server` (API), `artifacts/campusval-mobile` (Expo companion), `lib/*` (shared packages).

See [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) for local setup, environment variables, and deployment instructions.
