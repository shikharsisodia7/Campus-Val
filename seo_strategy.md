# SEO Strategy

## In scope
- Public landing page (`/`)
- Global crawlability and bot-governance files (`robots.txt`, `sitemap.xml`, `llms.txt`)
- Global HTML shell metadata in `artifacts/scu-advising/index.html`
- Social sharing metadata and crawler-visible branding assets for the public site

## Out of scope
- Authenticated application routes (`/courses`, `/planner`, `/schedule`, `/gpa`, `/transfer`, `/sync-workday`, `/policies`, `/advisor`, `/voice`, `/graduation-paths`, `/professors`, `/core-reqs`, `/compare`, `/advice`, `/evaluation`)
- Utility auth routes (`/sign-in`, `/sign-up`) except where global shell behavior affects crawlability or indexing
- Admin and internal-only pages
